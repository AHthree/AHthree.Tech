# ABUHANI.TECH — Final Stable Motion Website

GitHub Pages website for **AHthree/AbuHani.Tech**. This release keeps the symmetrical premium presentation and controlled transitions while prioritizing readability and speed.

## Final release changes
- No canvas, particle engine, mouse tracking, preloader, aurora blur, or continuous decorative animation.
- All text remains fully visible; scroll motion uses only a small transform and never depends on opacity.
- Six-service homepage slider uses low-cost opacity/transform transitions with no blur.
- Every service page includes a dedicated **Image Story** and **Motion Story** section.
- Six lightweight WebP placeholder images and six tiny MP4 placeholder clips are included so there are no broken media paths.
- Replace the placeholders later using the exact same filenames — no HTML changes required.
- Absolute GitHub Pages URLs use the exact repository case: `AbuHani.Tech`.
