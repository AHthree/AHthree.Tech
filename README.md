# ABUHANI.TECH — Final Royal Motion Build

This release is based on the previously approved ABUHANI.TECH reference build and refactored for performance, clarity and stable motion.

## Key behavior
- Royal dark hero + high-contrast light content sections
- Six-service 360° orbit using CSS transforms only
- Every orbit service image is a clickable link to the service page
- Service presentation auto-rotates with pause/previous/next controls
- No canvas particles, pointer tracking, preloader or continuous blur engine
- Service-page video autoplay is triggered only when the visitor reaches the visual story; videos are muted, inline and paused when out of view
- Appointment modal + FormSubmit delivery
- Persistent WhatsApp concierge
- Responsive mobile layout
