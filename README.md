# ABUHANI.TECH — Premium GitHub Pages Website

Static, responsive business website built for GitHub Pages.

## Included
- Futuristic animated home page with six-service slider
- Dedicated `/services/` overview page (prevents previous services 404)
- Six detailed service pages, including Legal Affairs Coordination
- Visual capability graphs, delivery timelines and image placeholders
- Appointment modal + contact form using FormSubmit email delivery
- Guided WhatsApp concierge with service-specific prefilled messages
- About, privacy, terms, thank-you and custom 404 pages
- Project-site-safe relative navigation

## Important setup
1. Deploy repository root with GitHub Pages: main / (root).
2. Form email delivery uses FormSubmit and may require a one-time activation from `ah.store2027@gmail.com` after the first submission.
3. The on-site WhatsApp concierge creates pre-filled service messages. True automated replies inside WhatsApp require WhatsApp Business/Cloud API and are not possible from static GitHub Pages alone.
4. Replace image-placeholder sections later with your own WebP/AVIF service artwork.
